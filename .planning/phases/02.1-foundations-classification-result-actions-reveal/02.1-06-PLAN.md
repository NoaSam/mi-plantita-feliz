<objective>
Crear el bottom sheet `AnonClassificationWall` que se abre cuando un usuario anónimo toca una de las cards de clasificación en el resultado de su identificación. El sheet persiste la intención (`{ plant_search_id, action, anonymous_id }`) en sessionStorage vía `writePendingClassification` (Plan 02) y enruta a `/signup` o `/login`. Plan 07 controla la apertura desde `PlantResultView` cuando `auth.user === null`.

Purpose: Es el gate de monetización del flujo anónimo: convierte una intención de clasificar en un signup/login. Sin este componente, los anónimos no tienen forma de guardar contexto (la card simplemente no haría nada), bloqueando el funnel completo.

Output: 1 archivo en `src/components/` que compone shadcn `Sheet` con copy verbatim, persistencia de intención antes de navegar, y los 2 eventos PostHog del wall cableados.
</objective>

    ```tsx
    import { useEffect } from "react";
    import { useNavigate } from "react-router-dom";
    import {
      Sheet,
      SheetContent,
      SheetDescription,
      SheetFooter,
      SheetHeader,
      SheetTitle,
    } from "@/components/ui/sheet";
    import { Button } from "@/components/ui/button";
    import {
      writePendingClassification,
      clearPendingClassification,
    } from "@/lib/pending-classification";
    import { track } from "@/lib/track";

    export interface AnonClassificationWallProps {
      open: boolean;
      intendedAction: 'home' | 'wild';
      plantSearchId: string;
      anonymousId: string;
      onOpenChange: (open: boolean) => void;
    }

    export default function AnonClassificationWall({
      open,
      intendedAction,
      plantSearchId,
      anonymousId,
      onOpenChange,
    }: AnonClassificationWallProps) {
      const navigate = useNavigate();

      // On open: persist intent to sessionStorage and fire shown event (D-01, D-02, D-14).
      useEffect(() => {
        if (!open) return;
        writePendingClassification({
          plant_search_id: plantSearchId,
          action: intendedAction,
          anonymous_id: anonymousId,
        });
        track("anon_classification_wall_shown", { intended_action: intendedAction });
      }, [open, intendedAction, plantSearchId, anonymousId]);

      const handleSignup = () => {
        track("anon_classification_wall_action", {
          action: 'signup',
          intended_action: intendedAction,
        });
        navigate("/signup");
      };

      const handleLogin = () => {
        track("anon_classification_wall_action", {
          action: 'login',
          intended_action: intendedAction,
        });
        navigate("/login");
      };

      const handleDismiss = () => {
        track("anon_classification_wall_action", {
          action: 'dismiss',
          intended_action: intendedAction,
        });
        clearPendingClassification();
        onOpenChange(false);
      };

      return (
        <Sheet open={open} onOpenChange={onOpenChange}>
          <SheetContent
            side="bottom"
            className="bg-background border-t-2 border-foreground p-6 rounded-t-2xl"
          >
            <SheetHeader className="items-center gap-2">
              <div
                className="size-14 mx-auto mb-3 rounded-full border-2 border-foreground bg-secondary flex items-center justify-center text-2xl"
                style={{ boxShadow: "var(--shadow-press)" }}
                aria-hidden
              >
                🔒
              </div>
              <SheetTitle className="font-display text-xl font-bold text-center">
                Necesitas una cuenta
              </SheetTitle>
              <SheetDescription className="font-body text-base leading-relaxed text-muted-foreground text-center mb-2">
                Para guardar esta planta en tu jardín o como descubrimiento, crea una cuenta o inicia sesión.{' '}
                <strong className="text-foreground font-semibold">No perderás esta identificación</strong>
                {' '}— al iniciar sesión, la planta aparecerá ya clasificada en tu historial.
              </SheetDescription>
            </SheetHeader>

            <SheetFooter className="flex flex-col gap-2 sm:flex-col">
              <Button
                variant="hero"
                size="default"
                onClick={handleSignup}
                className="w-full font-display text-base font-bold"
              >
                Crear cuenta
              </Button>
              <Button
                variant="outline"
                size="default"
                onClick={handleLogin}
                className="w-full font-body text-base font-semibold border-2 border-foreground"
              >
                Iniciar sesión
              </Button>
              <Button
                variant="ghost"
                size="sm"
                onClick={handleDismiss}
                className="w-full font-body text-sm text-muted-foreground underline underline-offset-2"
              >
                Volver sin guardar
              </Button>
            </SheetFooter>
          </SheetContent>
        </Sheet>
      );
    }
    ```

<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Component → sessionStorage | `writePendingClassification` writes a small JSON payload to a same-origin store. |
| Component → react-router navigate | Routes to `/signup` or `/login` (auth surface). |
| Component → PostHog (track) | 2 wall events fire with consent gating. |
| Sheet → Radix focus trap | Radix manages focus boundary while sheet is open. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-25 | Information disclosure | sessionStorage value visible to other same-origin scripts | accept | Per Plan 02 T-02.1-09: `plant_search_id` and `anonymous_id` are not secrets — both are already exposed via Supabase client and the localStorage anonymous_id. No PII or auth tokens in the wall payload. |
| T-02.1-26 | Tampering | A user cancels the sheet via Esc / click-outside (Radix-managed close) without dismiss tracking | accept | UI-SPEC § Component 7 tracking contract intentionally tracks only the 3 explicit actions (signup/login/dismiss). Implicit closes are part of normal Radix UX and would inflate dismiss counts. The `mp_pending_classification` is NOT cleared on implicit close — this is by design per D-01 ("survives navigations" until consumed or explicitly cleared). The 30-min TTL (D-02) handles stale intent. |
| T-02.1-27 | Repudiation | A user opens wall, persists intent, then signs in as a DIFFERENT account | mitigate | RLS is the primary defense (Plan 03 T-02.1-15): after `claim_anonymous_searches` runs, the row's `user_id` is set to whomever logged in. The UPDATE in `processPendingClassification` then runs under that user's RLS context. Cross-user theft requires sharing localStorage (device compromise) which is out of scope. |
| T-02.1-28 | DoS | sessionStorage quota exceeded | accept | Per Plan 02 T-02.1-10: the helper's try/catch silently degrades on quota error — user simply re-taps a card after login. Single small payload (~150 bytes) makes quota issues practically impossible. |
| T-02.1-29 | Spoofing | A different script triggers `onOpenChange(true)` directly to test the sheet's behavior | accept | Same-origin scripts can do this for any modal in the app; not a unique exposure. The wall's behavior on open (write to sessionStorage + fire impression event) is deterministic and auditable. |

</threat_model>
