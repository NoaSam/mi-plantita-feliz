## Decisions Made
- **Dedupe via module-level boolean:** Preferido sobre `useRef` porque `useRef` se resetea en cada mount; el flag module-level sobrevive a StrictMode (intended behavior). Sólo se resetea en page reload, que es lo que define "una sesión" para PostHog impressions.
- **Self-fetching UnclassifiedSection:** El componente importa el hook directamente en vez de recibir props. Razón: el hook ya hace el filtro por user/anonymous y devuelve `count: 0` para anon — extra layer of indirection no aporta. Si más adelante hay que mostrar otra fuente (e.g., un Storybook story), se puede pasar el hook como prop entonces.
