### 1. `supabase/migrations/2026MMDD000000_add_context_to_plant_searches.sql` (migration, schema-DDL)

**Analog:** `supabase/migrations/20260413000000_add_consensus_match_level.sql` (lines 1-10) — the only existing migration that mixes `add column ... text ... check (... in (...))` with a partial index.

**Existing migration to copy from (full file, 10 lines):**
```sql
-- Add consensus_match_level to record which tier produced the consensus.
-- Values: 'exact' | 'normalized' | 'genus' | NULL (no consensus or model failed)
alter table model_evaluations
  add column if not exists consensus_match_level text
    check (consensus_match_level in ('exact', 'normalized', 'genus'));

-- Index for analytics queries filtering by match level
create index if not exists model_evaluations_match_level
  on model_evaluations (consensus_match_level)
  where consensus_match_level is not null;
```

**What to change for this phase:**
- `not null default 'unclassified'` (instead of nullable) — see `02.1-SCHEMA-AUDIT.md` § 2.
- Composite partial index `(user_id, context, created_at desc) where user_id is not null` (multi-column, not single).
- The CHECK set per SCHEMA-AUDIT must be `('home', 'wild', 'unclassified')` (3 values — `unsaved` was dropped by SPEC).

**Naming convention** (locked by existing migrations in `supabase/migrations/`): `YYYYMMDDHHMMSS_<verb>_<noun>.sql`, lowercase snake-case. The phase output filename should follow `2026MMDD000000_add_context_to_plant_searches.sql` (CONTEXT.md uses that exact stem).

```typescript
export async function claimAnonymousSearches(): Promise<{ count: number }> {
  if (!hasAnonymousId()) return { count: 0 };
  const anonymousId = getAnonymousId();

  // Count rows BEFORE the claim (D-15: RPC doesn't return count, query before)
  const { count } = await supabase
    .from("plant_searches")
    .select("*", { count: "exact", head: true })
    .eq("anonymous_id", anonymousId);

  const { error } = await supabase.rpc("claim_anonymous_searches", {
    p_anonymous_id: anonymousId,
  });
  if (error) {
    console.warn("claim_anonymous_searches failed:", error.message);
    return { count: 0 };
  }
  clearAnonymousId();
  if (count && count > 0) {
    track("anon_searches_claimed", { count });
  }
  return { count: count ?? 0 };
}
```

```tsx
}
```
