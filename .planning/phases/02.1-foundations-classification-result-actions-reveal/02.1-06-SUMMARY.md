# Plan 02.1-06 Summary

**Bottom sheet for anonymous classification intent — persists to sessionStorage and routes to /signup or /login**

## Performance

- **Duration:** ~3 min (orchestrator inline)
- **Tasks:** 1
- **Files modified:** 0 (all-additive plan)

## Accomplishments
- `AnonClassificationWall.tsx` envuelve shadcn `Sheet` (side="bottom") con:
  - Icono 🔒 con sticker shadow
  - Título `Necesitas una cuenta`
  - Body con substring `<strong>No perderás esta identificación</strong>`
  - 3 CTAs: `Crear cuenta` (hero) → `/signup`, `Iniciar sesión` (outline) → `/login`, `Volver sin guardar` (ghost) → dismiss
- En `useEffect([open])` cuando `open === true`: `writePendingClassification({ plant_search_id, action, anonymous_id })` + `track("anon_classification_wall_shown", { intended_action })`. Los CTAs disparan `track("anon_classification_wall_action", { action, intended_action })` antes de navegar/cerrar.
- Dismiss limpia `clearPendingClassification()`; signup/login NO limpian (Plan 03 lo consume post-auth).

## Task Commits

1. **Task 1: Create AnonClassificationWall component** — `<hash>` (feat) — see git log for the actual hash, this is the only task in the plan.

## Files Created/Modified
- `src/components/AnonClassificationWall.tsx` — sheet component with persist-then-navigate ordering.

## Decisions Made
- **Implicit close NO tracked:** Solo el botón explícito `Volver sin guardar` dispara el evento `anon_classification_wall_action(action=dismiss)`. Esc / click-outside cierran el sheet (Radix lo gestiona) pero no inflan el funnel signal. Si en el futuro hace falta medir close-rate, se añade un onOpenChange wrapper.
- **Intent persiste a través de signup/login:** No se limpia en handlers de signup/login porque processPendingClassification (Plan 03) consume + clears post-auth. Si el usuario aborta el signup, el TTL de 30 min (D-02) limpia automáticamente.
