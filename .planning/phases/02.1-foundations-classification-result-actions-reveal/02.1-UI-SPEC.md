### Spacing rules for new components (locked)

- **Card stack gap (`ClassificationCards`):** `gap-3` (12px) on mobile, matching sketch 001A inline visual rhythm.
- **`UnclassifiedSection` outer top margin:** `mt-8` (32px) — visually separates from camera CTA without forming a hard divider; the dashed `border-t` from sketch is replaced with a `border-t-2 border-foreground/15` (Tailwind utility, no new token).
- **Thumbnail grid:** `grid-cols-4 gap-2` (8px) — matches sketch 003D phone 1.
- **History summary vertical margins:** `my-4` (16px) above list, `mb-2` (8px) below header.
- **`AnonClassificationWall` sheet padding:** `p-6` (24px); button stack uses `gap-2` (8px) per sketch.

### Touch targets

- All interactive surfaces ≥ 44 × 44px. Cards are full-width and ≥ 64px tall. Chip pill is non-interactive in v0 (per SPEC AC: "no filtros UI") — so chips do NOT need a 44px target.
- Icon-only "Cambiar" button on banner → wrapped in a `text` button with `min-h-11 px-3` (44px hit area despite small visual).

### Exceptions

- Chip pill (`ContextChip`) is intentionally smaller — `text-xs px-2 py-1` — because it is a status indicator, not an interactive control. **Documented exception.**
- Thumbnail squares in `UnclassifiedSection` use `aspect-square` with the smallest side ≥ 64px on a 414px viewport (4 columns ≈ 80px each minus gaps), which exceeds 44px target. ✓

The chip wild label uses `text-xs font-semibold` (12-13px bold) which **just** falls short of large-text AA. **FLAG (non-blocking)**: Consider darkening accent text or using `font-bold` for `chip-wild` to clear AA Large; or accept since the chip is decorative status, not load-bearing copy.

### 2. `ClassificationMorph.tsx`

**Purpose:** In-place transformation of the tapped card into a primary-green confirmation card with "Deshacer" inline. Replaces the tapped card slot. The other card fades to disabled.

**Visual spec (sketch 002C, locked):**
- Surface: `bg-primary text-primary-foreground border-2 border-foreground rounded-2xl shadow-[var(--shadow-press)] px-5 py-4`.
- Layout: `flex items-center gap-4`.
- Structure:
  ```
  [✓ icon — Lucide Check, size-6] [title + subtitle] [Deshacer button — text underlined, color: primary-foreground]
  ```
- Title (`Añadida a tu jardín` / `Guardada como descubrimiento`) — `font-display text-xl font-semibold leading-tight`.
- Subtitle (`Aparecerá con su frecuencia de riego.` / `Aparecerá en tu mapa.`) — `text-sm opacity-85 leading-snug`.
- Undo: `<button type="button" class="font-body text-sm font-semibold underline underline-offset-2 px-3 py-2 min-h-11">Deshacer</button>`. Min hit-target 44px high.

**Props:**
```ts
interface ClassificationMorphProps {
  action: 'home' | 'wild';
  plantSearchId: string;
  onUndo: () => void; // executor wires to use-classify-plant.revert
  onSettle: () => void; // fires after 5000ms — caller transitions to PersistentClassificationBanner
}
```

**Interaction states:**

| State | Visual | Motion |
|-------|--------|--------|
| Mount (replaces tapped card) | Slides into the slot the card occupied | 250ms `[0.16, 1, 0.3, 1]` (matches existing `PlantResultView` ease) — opacity 0→1 + scale 0.96→1 |
| Visible (5000ms window) | Static green card, ✓ visible, "Deshacer" interactive | none — countdown is internal `setTimeout`; no visible timer per CONTEXT.md (locked) |
| Undo pressed | Morph unmounts; cards re-mount | 200ms reverse — opacity 1→0 + scale 1→0.96 |
| Auto-settle (5s elapsed) | Morph + sibling card both unmount; `PersistentClassificationBanner` mounts in their slot | 250ms crossfade — Framer `AnimatePresence mode="wait"` |
| Cleanup on unmount | `clearTimeout` in `useEffect` return — per D-10 |

**Motion (Framer Motion, locked):**
```ts
// Morph entry / settle
<motion.div
  key="morph"
  initial={{ opacity: 0, scale: 0.96 }}
  animate={{ opacity: 1, scale: 1 }}
  exit={{ opacity: 0, scale: 0.96 }}
  transition={{ duration: 0.25, ease: [0.16, 1, 0.3, 1] }}
/>

// Other card fading to disabled
<motion.button
  animate={{ opacity: 0.35 }}
  transition={{ duration: 0.2, ease: 'easeOut' }}
  style={{ pointerEvents: 'none' }}
/>
```

Reduced-motion: `prefers-reduced-motion: reduce` → opacity-only crossfade (no scale), 100ms.

**A11y:**
- Wrap with `role="status" aria-live="polite"` — when morph mounts, screen readers announce: "Añadida a tu jardín. Aparecerá con su frecuencia de riego. Deshacer disponible."
- The `aria-live` region announces the title + subtitle once on mount.
- Deshacer button receives focus automatically on mount (`autoFocus` on the Deshacer button) so keyboard users can revert without searching. **Confirm not jarring** — alternative: do NOT autofocus, and use a separate `<span class="sr-only">` for the announcement. Locked default: **announcement via `aria-live`, no autoFocus**, because autofocus mid-flow is hostile to screen readers per WCAG 2.4.3.
- 5s timer pauses if user hovers / focuses Deshacer button (prevents premature settle while user is reaching for it). Implementation: `onMouseEnter` / `onFocus` on the morph element calls `pauseTimer()`; `onMouseLeave` / `onBlur` resumes. (Mobile users tapping Deshacer don't need pause — tap completes before timer fires.)

**Tracking events:**

## Accessibility contract

- **Color contrast:** Foreground/background AAA confirmed; primary AAA; muted AAA; accent text-on-coral borderline AA Large (FLAG, see Color section).
- **Focus order on `PlantResultView` (logged-in, unclassified):** Back button → hero photo (skip — non-interactive) → plant name (heading) → eyebrow (skip) → Card 1 → Card 2 → "Más sobre" eyebrow (skip) → accordion item 1 → accordion item 2 → accordion item 3 → "Volver a empezar".
- **Focus order on `PlantResultView` (logged-in, classified):** identical, with banner's "Cambiar" button replacing both cards.
- **Focus order during morph:** Back → plant name → morph card region (announced via `aria-live`) → "Deshacer" → disabled card (skipped — `tabIndex={-1}` while disabled) → eyebrow → accordion → reset.
- **Focus order on home with section:** existing camera → existing "Subir desde galería" (if present) → "Sin clasificar" heading → "Ver todas" → thumb 1 → thumb 2 → thumb 3 → thumb 4.
- **Live regions:**
  - `ClassificationMorph` is `role="status" aria-live="polite"` — announces the title + subtitle on mount.
  - `PersistentClassificationBanner` is `role="status"` (NOT `aria-live` — already-classified state is not a "new" announcement).
  - Error toast (sonner) uses sonner's built-in `aria-live="polite"`.
- **Reduced motion:** see Motion table.
- **Keyboard-only flow validation:** A user can perform the entire happy path (identify → classify home → undo → classify wild → settle → cambiar → re-classify) using only Tab, Shift+Tab, Enter, Space, Esc.
- **Screen-reader copy:** all emoji icons are `aria-hidden`; text-only labels carry meaning. `aria-label` overrides where text is decorative or duplicated.
- **Touch targets:** all interactive controls ≥ 44px. Confirmed for cards (≥64px), banner Cambiar (44px via `min-h-11`), morph Deshacer (44px), wall buttons (default `Button size` is 48px h), thumbnails (≥80px on 414px viewport), chevrons (parent button is the target).
- **Anonymous wall focus:** Radix `Sheet` traps focus; Esc closes; click-outside closes; close returns focus to the originating card. Spanish copy throughout.

## FLAG-level (non-blocking) notes for downstream consumers
