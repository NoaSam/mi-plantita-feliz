# Summary: Plan 03.1-01 — Leaflet Map Stack Foundation

## What Was Done

Installed the Leaflet map stack and wired the global CSS foundation for the Plant Map feature.
Three tasks executed atomically, each committed independently.

### Task 1: Installed map dependencies

Added to `package.json`:
- `dependencies`: `"leaflet": "^1.9.4"`, `"react-leaflet": "^4.2.1"`
- `devDependencies`: `"@types/leaflet": "^1.9.21"`

Versions locked per RESEARCH.md § Standard Stack. react-leaflet 4.2.1 is the latest React 18-compatible
release; v5.x requires React 19 (which would break this project).

### Task 2: Import order — leaflet CSS before project CSS

In `src/main.tsx`, inserted `import "leaflet/dist/leaflet.css"` immediately before `import "./index.css"`.
This order is load-bearing: Leaflet's default `.leaflet-div-icon` and `.leaflet-control-*` rules must
load first so that the project-level overrides added in Task 3 can win.

### Task 3: CSS overrides in src/index.css

Appended a clearly delimited block at the end of `src/index.css` with four override groups:

1. `.plant-map-pin` — `background: transparent; border: none` to strip Leaflet's default white-box
   wrapper from divIcon markers (RESEARCH.md Pitfall 3, CONTEXT.md D-09).
2. `.plant-map-pin:active > div, :focus-within > div` — `transform: scale(1.1)` for D-10 tap feedback.
3. `@media (prefers-reduced-motion: reduce)` — disables the scale animation for accessibility.
4. `.leaflet-control-zoom` — `display: none` (mobile uses pinch-to-zoom; UI-SPEC line 822).
5. `.leaflet-control-attribution` — `margin-right: max(2px, env(safe-area-inset-right))` for iOS PWA
   notch safety (UI-SPEC line 826).

Nothing existing in `index.css` was modified — only additions at EOF.
